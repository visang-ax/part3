# 탁구18강토너먼트 구조

## 전체 구조

- A조 9팀과 B조 9팀으로 시작한다.
- 각 조에서 조 우승팀을 1팀씩 뽑는다.
- A조 우승팀과 B조 우승팀이 중앙 결승에서 최종 우승을 결정한다.

## 조별 대진 구조

각 조는 같은 구조를 사용한다.

| 단계 | 경기 | 결과 박스 |
|---|---|---|
| 1차전 | 1번 vs 2번 | winner 1 |
| 1차전 | 3번 vs 4번 | winner 2 |
| 1차전 | 5번 vs 6번 | winner 3 |
| 1차전 | 7번 vs 8번 | winner 4 |
| 9번 경기 | winner 4 vs 9번 | winner 5 |
| 4강 진출 1 | winner 1 vs winner 2 | 결승 진출팀 1 |
| 4강 진출 2 | winner 3 vs winner 5 | 결승 진출팀 2 |
| 조 결승 | 결승 진출팀 1 vs 결승 진출팀 2 | 조 우승 |

## A조 id 구조

| 의미 | id |
|---|---|
| 1번-9번 원팀 | `tL1` - `tL9` |
| winner A1-A5 | `wL1` - `wL5` |
| A조 결승 진출팀 1 | `sL1` |
| A조 결승 진출팀 2 | `sL2` |
| A조 우승 | `cL` |

## B조 id 구조

| 의미 | id |
|---|---|
| 1번-9번 원팀 | `tR1` - `tR9` |
| winner B1-B5 | `wR1` - `wR5` |

| B조 결승 진출팀 2 | `sR2` |
| B조 우승 | `cR` |

## 최종 결승 id

| 의미 | id |
|---|---|
| 결승 | `F` |

## 9번 구조 설명

- 7번과 8번의 승자는 winner 4로 올라간다.
- winner 4는 9번과 직접 연결되는 구조를 가진다.
- 화면상 winner 5 자리는 9번을 유지하는 특수 규칙이 있다.
- winner 4 또는 winner 5를 클릭하면 결승 진출팀 2가 해당 번호로 결정된다.

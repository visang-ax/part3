## 박스 데이터

박스는 다음 구조로 관리한다.

```js
{
  id: "tL1",
  x: 22,
  y: 205,
  w: 103,
  h: 45,
  cls: "team",
  label: "1번"

```

좌표 `y`는 박스 중앙값이다. 실제 DOM top은 `y - h / 2`.

## 라인 연결 규칙

### pair 타입

- 각 후보에서 `busX`까지 가로선
- 후보 Y에서 부모 Y까지 수직선
- 부모 Y에서 부모 박스까지 가로선
- 조 우승 박스(`cL`, `cR`)로 들어가는 마지막 가로선은 그리지 않는다.

### bye 타입

- 9번에서 winner 5까지 가로선
- winner 4에서 winner 5까지 수직선

### final 타입

- A조 우승 오른쪽에서 결승 왼쪽까지 가로선
- 결승 오른쪽에서 B조 우승 왼쪽까지 가로선

## 승리 라인 애니메이션

승리 라인은 `strokeDasharray`와 `strokeDashoffset`을 사용한다.

```js
var len = path.getTotalLength();
path.style.strokeDasharray = len;
path.style.strokeDashoffset = len;
path.style.transition = "stroke-dashoffset .42s ease";
path.style.strokeDashoffset = "0";
```

초기 로드 시에는 애니메이션 없이 바로 표시한다.

## 승자 클릭 처리 순서

1. 클릭한 id로 `matchByKid[id]`를 찾는다.
2. 하위 승자가 필요한 박스인데 아직 선택되지 않았으면 alert 후 중단한다.
3. 9번 특수 규칙을 먼저 처리한다.
4. 이미 선택된 후보를 다시 클릭하면 선택 해제한다.
5. 새 후보를 클릭하면 `winSel[parentId] = clickedId`로 저장한다.
6. 상위 라운드 선택값 중 영향을 받는 값은 삭제한다.
7. 저장 후 `recompute(true)`를 실행한다.

## 9번 특수 처리

### A조

- `tL9` 클릭:
  - `winSel.wL5 = "tL9"`
  - `store.wL5` 제거
  - `winSel.sL2 === "wL4"`이면 `winSel.sL2 = "wL5"`
- `wL4` 클릭:
  - `winSel.wL5 = "tL9"`로 유지
  - `store.wL5` 제거
  - `sL2`가 `wL4`이면 해제, 아니면 `sL2 = "wL4"`

### B조

- `tR9` 클릭:
  - `winSel.wR5 = "tR9"`
  - `store.wR5` 제거
  - `winSel.sR2 === "wR4"`이면 `winSel.sR2 = "wR5"`
- `wR4` 클릭:
  - `winSel.wR5 = "tR9"`로 유지
  - `store.wR5` 제거
  - `sR2`가 `wR4`이면 해제, 아니면 `sR2 = "wR4"`

## recompute 순서

`recompute(animate)`는 다음 순서로 실행한다.

1. `wonSet` 생성
   - `winSel`의 값으로 선택된 후보를 승리 처리
   - 상위 박스가 자기 하위 선택값과 같은 텍스트를 표시하면 상위 박스도 승리 처리
2. `lostSet` 생성
   - 선택된 경기에서 선택되지 않은 후보를 패자 처리
   - 9번 특수 예외 반영
3. 패자 경로 전파
   - 패한 박스가 내부적으로 가리키던 원팀도 패자 처리
4. 5번 경로 선택 시 7/9번 경로 패자 처리
5. DOM 텍스트 업데이트
6. `won`, `lost`, `champ-win` 클래스 반영
7. 승리 라인 표시/숨김
8. 패자 라인 클래스 반영
9. 결승 폭죽 조건이면 결승 텍스트를 잠시 비우고 폭죽 후 표시

## 패자 전파

```js
function markLostPath(id){
  var picked = winSel[id];
  if(!picked || lostSet[picked]) return;
  lostSet[picked] = true;
  markLostPath(picked);
}
```

패자 박스 안에 올라와 있던 실제 원팀까지 흐리게 만들기 위해 사용한다.

## 화면 스케일

```js
function fit(){
  var pad = 20;
  var scale = Math.min(
    (window.innerWidth - pad*2) / W,
    (window.innerHeight - pad*2) / H
  );
  canvas.style.transform = "scale(" + Math.min(scale, 1.18) + ")";
}
```

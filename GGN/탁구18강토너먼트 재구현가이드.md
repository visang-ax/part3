# 탁구18강토너먼트 재구현 가이드

이 문서 세트는 `탁구18강토너먼트.html` 파일이 없어도 같은 화면과 동작을 다시 구현하기 위한 기준이다.

## 문서 구성

1. `탁구18강토너먼트 구조.md`
   - 대진표 구조, 각 박스의 의미, A조/B조 배치 흐름을 정의한다.

2. `탁구18강토너먼트 디자인.md`
   - 캔버스, 색상, 좌표, 박스 크기, 라인 스타일, 상태 스타일, 폭죽 시각 효과를 정의한다.

3. `탁구18강토너먼트 기능명세.md`
   - 클릭, 편집, 저장, 승자/패자 처리, 9번 특수 규칙, 결승 처리 규칙을 정의한다.

4. `탁구18강토너먼트 구현명세.md`
   - 실제 구현에 필요한 id 규칙, 데이터 구조, 상태 계산 순서, 라인 계산 알고리즘을 정의한다.

## 구현 목표

- 기준 화면 크기 `1320px x 930px`의 단일 토너먼트 보드를 만든다.
- A조 9팀, B조 9팀을 좌우 대칭으로 표시한다.
- 각 조 우승팀이 중앙 결승으로 이어진다.
- 클릭으로 승자를 선택하고, 승리/패자 상태와 라인이 즉시 반영된다.
- 더블클릭으로 박스 텍스트를 편집할 수 있다.
- 새로고침 후에도 편집 텍스트와 승자 선택 상태가 유지된다.
- 결승 승자가 새로 정해지면 화면 전체에 큰 폭죽 효과가 한 번 나온 뒤 결승 숫자가 표시된다.

## 재구현 순서

1. `구조.md`를 보고 박스 id와 대진 흐름을 만든다.
2. `디자인.md`를 보고 캔버스, 좌표, 박스, 라인을 배치한다.
3. `구현명세.md`를 보고 `boxes`, `matches`, `winSel`, `store` 구조를 만든다.
4. `기능명세.md`를 보고 클릭/편집/저장/패자 전파/9번 특수 규칙을 연결한다.
5. 모든 라운드에서 승자 선택, 해제, 패자 흐림, 9번 특수 흐름, 결승 폭죽을 검증한다.

## 반드시 유지할 것

- 파일 저장 키: `pp_bracket_18`
- 기준 캔버스: `1320 x 930`
- A조 우승 박스 좌표: `left 455px`
- B조 우승 박스 좌표: `left 735px`
- 결승 박스 좌표: `left 612px`
- 9번 특수 규칙은 A조/B조 동일 적용
- 패자 박스와 패자 라인은 같은 회색 톤으로 처리
- 7/8번 winner와 9번 winner 사이 세로 라인은 상황에 따라 희미하게 처리

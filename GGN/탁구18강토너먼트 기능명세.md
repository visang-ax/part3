# 탁구18강토너먼트 기능 명세

## 클릭

- 박스 클릭: 해당 경기의 승자 선택 또는 선택 해제
- 더블클릭: 박스 텍스트 직접 편집
- Enter: 편집 종료
- 초기화 버튼: 저장된 텍스트와 승자 선택을 모두 초기화

## 선택 제한

상위 라운드 박스를 클릭하려면 해당 박스 안에 올라온 하위 승리팀이 먼저 선택되어 있어야 한다.

조건을 만족하지 않으면 다음 alert를 표시한다.

```text
승리팀을 선택하세요.
```

## 승리 상태

- 선택된 후보는 승리 상태가 된다.
- 승리해서 다음 단계에 올라간 박스도 승리 상태가 된다.
- 같은 팀이 여러 단계로 올라가면 원팀 박스와 모든 상위 박스가 함께 승리 상태가 된다.

## 패자 상태

- 선택된 경기에서 선택되지 않은 후보는 패자 상태가 된다.
- 한 번 이겼던 박스라도 이후 라운드에서 패하면 패자 상태가 우선된다.
- 패한 후보 박스 안에 올라와 있던 실제 원팀도 함께 패자 상태가 된다.
- 패자 후보로 이어지는 라인도 패자 라인 상태가 된다.
- 패한 경로에 남아 있던 이전 승리 초록 라인은 숨긴다.

## 9번 특수 규칙

A조와 B조에 동일하게 적용한다.

- 9번을 클릭하면 9번 원번호와 winner 5가 활성화된다.
- 7/8번 쪽 winner 4를 클릭해도 winner 5 자리 숫자는 9번으로 유지한다.
- winner 4 또는 winner 5를 클릭하면 결승 진출팀 2가 해당 번호로 활성화된다.
- 7번 또는 9번이 결승 진출팀 2로 올라가면 7번과 9번 사이의 중간 세로 연결선은 희미하게 처리한다.
- 9번이 최종 선택되면 7/8번 경로는 패자 처리된다.
- 5번 경로가 결승 진출팀 2로 올라가면 7/9번 경로는 패자 처리된다.
- winner 4는 9번과 대결 전까지는 패자로 처리하지 않는다.

## B조 대칭

- B조는 A조와 같은 규칙을 좌우 대칭으로 적용한다.
- `winner B3/B4/B5`는 `B조 결승 진출팀 2`로 연결된다.
- B조 9번도 winner 5 자리에서 9번을 유지한다.
- B조의 7/8번 경로와 9번 경로도 A조와 같은 패자/승자/라인 처리 규칙을 따른다.

## 결승

- A조 우승과 B조 우승이 결정된 뒤 결승 승자를 선택할 수 있다.
- 결승 승자가 새로 정해질 때만 폭죽 애니메이션을 실행한다.
- 저장된 상태를 처음 로드할 때는 폭죽을 실행하지 않고 결과를 바로 표시한다.
- 결승 텍스트는 폭죽 애니메이션 종료 후 표시한다.

## 텍스트 편집

- 모든 박스는 더블클릭으로 텍스트 편집 가능
- 기본 텍스트와 같으면 저장하지 않는다.
- 사용자가 바꾼 텍스트는 `localStorage`에 저장한다.

## 저장

- 저장 키: `pp_bracket_18`
- 저장 항목
  - 사용자 편집 텍스트
  - 승자 선택 상태 `__win`
- 초기화 시 저장값 전체를 삭제한다.
